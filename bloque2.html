Bloque 2 · HSK4 + HSKK Intermedio

Expresar progreso con 越来越

Escucha 10 oraciones, repítelas y descubre cómo el chino expresa cambios graduales: algo se vuelve más bonito, más difícil, más rápido o más interesante.

Objetivo del bloque

Al terminar este bloque, el estudiante podrá hablar de progreso, cambios y mejora personal usando 越来越, 变得, 得 y 提高了很多, estructuras muy útiles para respuestas del HSKK intermedio.

Reconocer cambios

Identificar cuándo una cualidad aumenta gradualmente.

Hablar de progreso

Explicar cómo mejora el chino, la pronunciación, la escucha o una habilidad.

Usar 变得

Decir que una situación “se vuelve” diferente con el tiempo.

Responder HSKK

Construir respuestas orales sobre aprendizaje, hábitos y cambios personales.

Ruta de aprendizaje

1
Escucha el cambio
Detecta la palabra 越来越 dentro de la frase.
2
Repite con ritmo
Practica la secuencia completa sin separar demasiado las palabras.
3
Encuentra el patrón
Observa qué aparece después de 越来越.
4
Transforma
Cambia el adjetivo para crear nuevas frases.
5
Produce oralmente
Habla de tu propio progreso en chino.

Explicación gramatical

越来越 se usa para expresar que una cualidad aumenta o cambia gradualmente. Es una estructura muy útil para hablar de aprendizaje, progreso, clima, ciudad, tecnología o intereses personales.

越来越 + adjetivo / estado = cada vez más...
变得 + 越来越 + adjetivo = volverse cada vez más...
verbo + 得 + 越来越 + adjetivo = hacer algo cada vez más...
EstructuraUsoEjemplo
越来越 + adjetivoExpresa aumento gradual de una cualidad.越来越好 / 越来越热
变得 + 越来越 + adjetivoIndica que algo se vuelve progresivamente diferente.变得越来越漂亮
verbo + 得 + 越来越 + adjetivoDescribe cómo una acción mejora o cambia.跑得越来越快
提高了很多Expresa mejora notable.汉语水平提高了很多
对……越来越感兴趣Expresa interés creciente.对中文越来越感兴趣

Actividad 2: Transforma

  • 我的中文越来越好了 → 我的发音越来越……
  • 天气越来越热了 → 天气越来越……
  • 我对中文越来越感兴趣了 → 我对中国文化越来越……
